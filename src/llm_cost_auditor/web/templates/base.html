Pricing-stage build This build implements ingest and pricing — connectors, decoding, the Anthropic adapter, retry classification, the run store, coverage, and baseline spend at public list prices. There are no analyzers yet, so no page here shows a finding, a saving, or a recommendation; a run page shows what its traffic cost and nothing about what it could have cost. Every figure is computed from the run record on disk and the price catalog.
